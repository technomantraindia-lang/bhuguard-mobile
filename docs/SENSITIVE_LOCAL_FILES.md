# Sensitive files — transfer privately (do not commit)

These items must stay on trusted machines only. Prefer a password-protected archive or encrypted USB when moving between the office desktop and a laptop.

## Always keep local / private

| Item | Typical path | Notes |
|------|--------------|-------|
| Local env | `.env`, `.env.development`, `.env.demo` | Copy from `.env.example` on each machine |
| Debug keystore | `android/app/debug.keystore` | Regenerated by Android/Expo prebuild if missing |
| Release keystore | `*.jks` / `*.keystore` (if you create one) | Never commit; store password separately |
| Gradle signing props | local `gradle.properties` overrides | Do not put store passwords in Git |
| Firebase / Google | `google-services.json`, `GoogleService-Info.plist` | Not present in this project currently |
| EAS token | user machine / CI secret | Use `eas login`, never commit tokens |
| Built binaries | `releases/*.apk`, `*.aab` | Ignored by Git |

## Safe to regenerate on the laptop

- `node_modules/` → `npm install`
- `.expo/` → created by Expo
- `android/` / `ios/` → `npx expo prebuild` when native builds are required

## Not required on the laptop

- Local Laravel
- Local MySQL
- Office LAN IP
- Cloudflare tunnel URL
